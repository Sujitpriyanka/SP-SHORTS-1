# SP SHORTS — Android demo starter (source project)

Reference: user-supplied screen recording `53727.mp4` and SP SHORTS logo `51910.png`.

## Implemented in this starter
- Offline demo login (no OTP)
- Discover navigation with local Like / Follow / Comment counters
- ChatRoom and simulated local message action
- Create screen with a demo video counter (NOT actual capture/upload)
- Profile edit (in-memory only)
- Demo wallet recharge/withdrawal counters (NO money movement)
- Creator verification informational checklist
- Settings/logout

## Not yet implemented
Actual media playback/upload, live streaming, network accounts, Google sign-in, persistent database, payments, agency management, ranking, creator verification, detailed pixel-perfect UI, and production security. Demo data resets when the app process is killed. This is a first starter, not a complete functional clone.

## Build
Open this folder as a project in Android Studio with Android SDK 35 installed. Let Gradle sync, then Build > Build Bundle(s) / APK(s) > Build APK(s). Output typically: app/build/outputs/apk/debug/app-debug.apk.

No APK was built in the current environment (Android SDK/Gradle not available). This project needs a build and runtime test on an Android device before use.
